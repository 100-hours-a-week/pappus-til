- 각각의 분야별로 전문적인 agent로 분리해서 각 분야에서 필요한 과제들을 작성하는 방식으로 작성함.
- 사전에 분류하고 설정하는 시간이 가장 중요하고 오래 걸리는 듯.

### 웹툰
- 웹툰을 작성하면 배경이나 인물이 바뀌는 모습들을 보여서 검수의 필요성을 느낌
- 웹툰 품질 검증 에이전트를 할당해서 이를 검증하도록 함. -> 개인적인 생각: 사람이 검수하는 것이 아니라 정확도가 많이 올라가지는 않을 것 같은데?

### 할루시네이셔 원인
- 요청에 대한 데이터가 부족하거나 질문이 구체적이지 않을때 발생함. 
- 방대한 작업을 한번에 진행하면, 방대한 데이터를 다루다보니까 처리가 안좋아지는데 병렬적으로 여러 에이전트에 맡기거나, 분할해서 적용하면 상당히 효과가 좋아짐.

### AI의 보조
- 계속 지시해야함
- 중간 품질을 직접확인 (검수)
- 긴 작업은 쉽게 흔들림

#### 오래된 작업시 발생 문제
1. 맥락 소실: 대화가 길어질수록 앞 내용을 놓치기 쉬움
2. 중간 상태 누락: 어디까지 했는지 기록이 없으면 다시 해맴.
3. 관한 한 번의 시도: 큰일을 한번에 하려면 와르르 무너짐.
4. 실수 누적

- 한번의 많고 과한 지시보다는 짧고 반복적인 지시가 더욱 효과적임.

#### Agent 사용방식
- subAgent: 하나의 에이전트가 작업하여 집중형 단일 작업에 적합
- Agent Team: 팀원끼리 직접 메시지를 하며 공유 작업 목록을 조율하면서 작업하여 협업이 필요한 큰 단위의 작업에 적합 (토큰 비용은 역시 Agent Team이 큼, codex는 제공하지 않는 기능임.)
    - setting하고 싶으면 클로드에 세팅하는 방법 나와있음.
